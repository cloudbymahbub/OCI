## 🔐 IAM Learning Path

```text
Tenancy
   ↓
Compartments
   ↓
Users
   ↓
Groups
   ↓
Policies
   ↓
Permissions
   ↓
Resources
```

Example OCI policy structure:

```text
Allow <subject> to <verb> <resource> in <location>
```

Example:

```text
Allow group CloudEngineers to manage instances in compartment Practice
```
